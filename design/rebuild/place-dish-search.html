What changes from the current build

  • Search's custom header becomes the native one. Large title, the system search bar, and the Places / Dishes / People / Saved switch stays one equal-width segment with the filter disc at its end (round 5), muted on People.
  • Before typing, recent searches replace "Nearby". The contract asks for location only on Near me and the place picker, so Search no longer opens on a location list. Saved still shows your whole list before typing.
  • An active search closes with a glass ✕, iOS 26's own cancel, instead of a text button.
  • Place and Dish get the inline native bar with a glass back disc; the place name moves into the bar as you scroll. The tab bar stays on both, minimising as you scroll.
  • Aggregates: stars to the nearest half, numbers to one decimal: a 4.6 prints 4.6 beside four and a half stars, on the menu, the chips, the dish header and search rows. Your own scores print exactly.
  • The menu keeps its receipt, numbering and Edge B, now in rating order with unscored dishes last as empty slots, as the server sends them.
  • The dish page keeps the build's order: reviews as avatar, handle and score, then More to explore (each tag opens its dishes) and More like this.
  • The dish sheet loses its Done pill. The corner tick saves, matching every other edit. It still fixes the name only.

States kept from the vocabulary: skeleton rows for first load, the letter tile for any dish without a photo, and a date chip on results whenever a date window is on (search counts then follow the window).

Decided

  • Search scopes: one equal-width switch with the filter at its end (round 5); one filter sheet; pills only while a filter is on.
  • The Place page opens on the menu, with the visits woven in under it, yours first.
  • The tab bar stays on Place and Dish.
  • Pushed pages use the inline native bar with a glass back disc.
  • An unrated dish is an empty score slot everywhere.
  • Aggregates: stars to the nearest half, numbers to one decimal.
  • Location is never asked on Search; recents fill the space before typing.
