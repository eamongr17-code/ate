The root cause. We've been tuning one number between two settings that fight each other. The blur we use is Apple's frosted material, and that material is a light grey wash. Over Ate's near-black page it can only make the band brighter, and over the linen page it makes it whiter. The more page colour we lay on top, the less you see the glass. The less we lay on, the more you see the grey. No value of that number gives both glass and a band that matches the page. So the fix has to be a different kind of header, not another opacity.

Now: build 196

For reference. Frosted material with 15% page colour on top. In dark, the band is lighter than the page under it.

A. iOS 26's own edge blurRecommended

We delete our frost and use the system's soft scroll edge, which every iOS 26 app uses. Content blurs more the closer it gets to the top and dissolves into the page colour. There's no grey wash, so it can't get brighter than the page. Buttons stay Liquid Glass. Headers keep today's behaviour: the root header slides away as you scroll down, and the page name moves into the bar on pushed pages.

Good
  • Glass you can see through, and it never changes the page's colour
  • Apple's own effect, so it matches the tab bar and the glass buttons
  • Least code: our frost is deleted, not tuned
Risk
  • Build 92 showed a lighter band with this effect over white slips in light mode. I'll check whether that came from the old bar background we had then, and set the scroll view to the page colour so the system fades into linen, not white
  • Apple sets how strong it is; we can't tune it

B. Page colour, no blur

The header is the page colour itself, solid behind the title and easing out below it. This is build 180, which you liked, on every screen. It can never be brighter or darker than the page, in either mode, because it is the page's colour.

Good
  • Zero risk of a band in either mode
  • Calm and editorial, fits the journal
Trade-off
  • No glass: content disappears under the header rather than showing through

C. No header bar, floating buttons only

The title scrolls away with the page. Only the Liquid Glass buttons stay, floating over content, as on Apple Music's album pages. The page colour sits behind the clock only, so the time stays readable.

Good
  • Most room for content; nothing to mismatch
  • Glass only where Apple uses it: on the buttons
Trade-off
  • No page name in the bar once you've scrolled (pushed pages lose the serif name you approved this morning)
  • Journal/Lists switch is only reachable at the top (tap the clock to jump there)
