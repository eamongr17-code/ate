Bug button and feedback sheet

A bug at the top right of the Journal opens one sheet: what happened, any screenshots, send. The build, device and the last screens you visited go with it automatically. It is there for testers only: TestFlight builds show it, an App Store build won't.

Phones are live size (iPhone 17 Pro). Icons are stand-ins: the build uses Lucide’s bug, like every other icon in Ate.

With the keyboard dismissed, the build and device show in fine print at the bottom, so testers can see what gets sent. The sheet never asks for photo access; if Ate doesn't have it, only the + shows.

3. What happens after Send

The report lands in Supabase, then becomes a GitHub issue (a repeat of an open issue is added to that one instead). Every few hours a scheduled triage run fixes clear bugs and ships them in the next TestFlight build. Anything visual, any feature idea, and anything it's unsure of comes to you in one batched list. Nothing on this page changes the rest of the app.
